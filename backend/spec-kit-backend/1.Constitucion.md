# Constitución del backend

Backend REST de gimnasio construido con TypeScript, Node.js 20+, Hono, PostgreSQL y una arquitectura de tres capas: rutas/controladores, servicios y repositorios.

La aplicación exporta `app` como `default` para Vercel. Las rutas de clientes requieren JWT; el cierre de sesión del MVP informa al cliente que debe eliminar el token, porque JWT es stateless. Las contraseñas nuevas se almacenan con bcrypt y 8 saltos. El administrador inicial en texto plano se migra automáticamente a bcrypt después de un login correcto.

## Ejecución

1. Copiar `.env.example` a `.env` y configurar `DATABASE_URL` apuntando a `gimnasiodb`.
2. Instalar dependencias con `npm install`.
3. Ejecutar localmente con `npm run dev` o compilar con `npm run build`.
4. Usar primero los scripts SQL de la carpeta raíz `db`.
